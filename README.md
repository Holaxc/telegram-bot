# Telegram Bot

Telegram-бот на Python для автоматизации взаимодействия с пользователями.

## Возможности

- Обработка команд и сообщений пользователей
- Inline-кнопки и интерактивное меню
- Работа с пользовательскими данными
- Отправка текстовых и медиа-сообщений
- Хранение данных
- Асинхронная обработка запросов

## Стек

- Python 3
- aiogram
- SQLite
- asyncio

## Структура

```text
telegram-bot/
├── bot.py
├── welcome.png
├── voice.ogg
└── README.md
```

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать переменную окружения с токеном Telegram-бота:

```env
BOT_TOKEN=your_token_here
```

Запустить:

```bash
python bot.py
```

## Безопасность

Токены и другие секретные данные не хранятся в репозитории. Для конфигурации используются переменные окружения.
